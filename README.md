# artus-demo-repo

A deliberately small Node project (no dependencies) used to record the
[Artus](https://github.com/eupakhomov/artus) demo: a sales-report CLI and a minimal HTTP service.

```bash
npm test                 # node --test
node src/cli.js          # print the report
npm start                # serve it on :3000
```

Some bugs here are intentional — the demo sessions fix and review them.
